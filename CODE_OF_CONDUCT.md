# Code of conduct

Give specific feedback about the work, accept good-faith disagreement, and respect others’ time and privacy. Harassment, discrimination, threats, and sharing private information without permission are unacceptable.

Report concerns to a maintainer through an existing private contact channel. If the concern involves that maintainer, contact another maintainer if available. Include only relevant evidence. Maintainers should limit disclosure, can remove harmful material or restrict participation, and must not retaliate. See the [security policy](SECURITY.md) for vulnerabilities.
