# Notices for the Athena analysis WASM payloads

These are source notices for the ARM64 candidate built at `16f37e2`. The local app ZIP already contains the CPython and QuickJS-ng notices; the additional copies in this directory are for assembling the release notice pack. They do not cover Photon, `quickjs-wasi` or its extension payloads, or every possible dependency of the analysis runtimes.

Both WASM name sections include `__wasilibc_initialize_environ`, `__multi3`, `__ashlti3`, `__udivti3`, `dlmalloc`, and `dlfree`. The two SDKs pin different source commits, but the copied [wasi-libc notice](LICENSE), [Apache with LLVM exception](LICENSE-APACHE-LLVM), [Apache](LICENSE-APACHE), [MIT](LICENSE-MIT), [cloudlibc](cloudlibc-LICENSE), [musl](musl-COPYRIGHT), [musl-fts](musl-fts-COPYING) and [compiler-rt](compiler-rt-LICENSE.TXT) files are byte-identical across both pinned versions. The identical [`dlmalloc/src/malloc.c` header](https://github.com/WebAssembly/wasi-libc/blob/ac020b86fd44bafe60aa4fa12f407d16e3731329/dlmalloc/src/malloc.c#L1-L6) credits Doug Lea and refers to [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). The upstream wasi-libc notice also names emmalloc; the function names above establish only the observed allocator.

## CPython libraries

The function names `XML_SetHashSalt16Bytes`, `PyInit__sha2`, `_hmac_compute_sha2_256`, and `mi_option_init`, together with the [CPython 3.15.2 module definitions](https://github.com/python/cpython/blob/v3.15.2/Modules/Setup.stdlib.in), identify libexpat, the HACL* SHA-2 implementation, and mimalloc. See [Expat's COPYING](cpython-expat-COPYING) from [`Modules/expat`](https://github.com/python/cpython/blob/v3.15.2/Modules/expat/COPYING), the [HACL* SHA-2 header](cpython-hacl-SHA2-LICENSE.txt) from [`Modules/_hacl/Hacl_Hash_SHA2.c`](https://github.com/python/cpython/blob/v3.15.2/Modules/_hacl/Hacl_Hash_SHA2.c), and the [mimalloc 2.5.2 license](mimalloc-LICENSE.txt) from [upstream](https://github.com/microsoft/mimalloc/blob/v2.5.2/LICENSE). [CPython's vendored header](https://github.com/python/cpython/blob/v3.15.2/Include/internal/mimalloc/mimalloc.h) declares `MI_MALLOC_VERSION 20502`, and its [`alloc.c`](https://github.com/python/cpython/blob/v3.15.2/Objects/mimalloc/alloc.c) also carries the original `Copyright (c) 2018-2024, Microsoft Research, Daan Leijen` notice.

The extracted `python.wasm` SHA-256 is `dd076791fb6d1286a5dfe105852dfb3367e10562de68ca0a618e615625cdf636`; the extracted `qjs.wasm` SHA-256 is `2c218412cb8b17e46ee91bea7556ec38f5b9b6bd6312fddd3ceeed14aa71eaaa`. The name-section check identifies components with retained names; it does not establish every source file linked into either binary.
