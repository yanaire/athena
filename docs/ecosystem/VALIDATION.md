# 이번 스킬·조사 변경의 검증 범위

검증일: 2026-11-20. 이 기록은 신규 자체 스킬과 조사 문서에만 적용된다. Athena 런타임 변경이나 플러그인 설치/실모델 E2E 시험을 수행한 기록이 아니다.

## 파일과 구조

- 자체 `SKILL.md` 12개에 스킬 작성 가이드의 `quick_validate.py`를 실제 실행해 12개 모두 형식 검사를 통과했다.
- frontmatter는 `name`·`description`이며 폴더 이름과 일치한다. 초기 안내 placeholder는 제거했다.
- 카탈로그는 JSON 파싱에 성공했고 자체 스킬 12개, 외부 스킬 후보 10개, 도구 후보 28개의 각 ID가 중복되지 않는다.
- 자체 스킬 경로의 실제 존재와 `contentSha256`을 대조했다. SHA-256은 해당 파일 바이트에서 계산했다.
- Markdown의 상대 파일 링크, 코드 블록 균형, 로컬 임시 경로·인증 정보의 혼입 여부를 점검했다.
- 외부 스킬의 특정 커밋, 개별 라이선스 URL과 원문 blob SHA를 카탈로그에 남겼다. 라이브러리의 선택 배포물 전체 감사는 수행하지 않았다.

## 제한된 응답 시나리오

두 개의 별도 평가 세션에 실제 스킬 파일과 작은 입력, 읽기 전용이라는 가상의 Athena capability 목록을 전달했다. 평가 세션은 해당 요청에 응답했고, 아래 동작을 관찰했다. 이 평가 세션은 Athena의 Pi 세션이나 사용자 로컬 Qwen 모델이 아니다. 실제 host policy enforcement와 도구 실행을 시험한 것으로 해석하지 않는다.

| 스킬·입력 | 관찰한 응답 | 검증하지 않은 것 |
|---|---|---|
| scientific-figure: ECG 관측점 3개, plotting/write 도구 없음 | 축·단위·캡션 설계만 제공하고 파일 미생성·다운로드 링크 없음으로 표시 | 실제 그림 생성·시각 검사 |
| knowledge-promotion: 현재 doc-7 revision 3, pass 검토는 revision 2, 저장 도구 없음 | 버전 불일치를 지적하고 proposal_only·receipt null을 반환. 검증됨/저장됨으로 표시하지 않음 | DB 버전 충돌·저장·복구 |
| statistical-analysis: A/B/C의 전후 값 10→11, 12→13, 9→10 mV, 분석 도구 없음 | 평균 변화 +1 mV를 수기 계산으로 설명하고 p값·신뢰구간·유의성·인과 결론을 만들지 않음 | 통계 엔진·모델 성공률 |
| units-and-dimensions: 문장에 1000 µV만 있고 CSV/write 도구 없음 | 1 mV라는 수기 환산을 제공하고 변환 파일은 미생성으로 표시 | CSV 일괄 변환·artifact 등록 |

첫 통계 응답 검토에서 도구가 없다는 이유로 간단한 수기 요약까지 지나치게 제한할 수 있음을 확인했다. 단위·통계·글쓰기 절차에 식과 방법을 밝힌 수기 검산을 허용하도록 보완한 뒤, 통계와 단위 요청을 새 평가 세션에서 다시 확인했다. 최종 파일 해시는 카탈로그에 반영했다.

## 문서 대조와 한계

문서 간 최초 활성화 대상을 `research-intake / source-provenance / data-quality`로 통일했다. 독립 검토는 별도 세션·근거 접근이 준비된 뒤 연결할 다음 대상으로 표시했다. 외부 스킬 후보와 플러그인 후보의 서로 다른 상태 필드도 구분했다.

이 변경은 형식과 제한된 응답 동작의 근거를 제공한다. 12개 스킬 모두의 실제 자동 선택, 사용자 모델별 정확도, 모든 플러그인의 설치·기능·성능, OS별 격리, 라이선스 의무 전부의 충족을 검증하지 않았다. 다음 구현자는 [IMPLEMENTATION.md](IMPLEMENTATION.md)의 첫 PR 인수 범위로 실제 스킬 로딩과 M2 계산 경로를 연결해야 한다.
