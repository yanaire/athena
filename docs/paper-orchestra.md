# Writing a manuscript in Athena

Open a project conversation and enable offline analysis in its execution settings. In Research → Manuscript, add UTF-8 material or a published data result, then select the sources, title and objective. Generate an outline, or enter one to eight headings. Save edits to the outline before starting **Write and review**. Each start is an explicit Pi request using the conversation's pinned model. Cancel stops the existing run. Opening a project after a restart lists saved manuscripts and partial work without starting a new request.

The parent invokes a bounded host workflow. One child returns a structured draft for each heading. The editor calls a host publication tool which executes the bundled offline QuickJS through the existing process queue. Its actual Markdown and JSON evidence map must pass normal artifact verification. A fresh child receives the frozen sources and both artifacts, reads them through the granted file tools, and submits claims, citations and figure-data checks through ResearchLedger. The host records evidence quotes, offsets and source versions. Figure links include the data artifact, variable, unit, transformation and caption. Textual checks and independent reviewer judgments cannot establish visual correctness or reproduce an experiment.

A changes-required verdict permits at most one further editor turn, using the same editor and a new reviewer. This uses three direct children initially and four with revision. A configured child limit of three preserves the first verdict. Model slots are released while waiting. Source, artifact, queue and job limits still apply. A manuscript run has no separate global price, token or wall-clock budget. Partial drafts and version-specific unresolved findings remain in SQLite. The generic task retry cannot advance a manuscript, and there is no automatic continuation.

The host issues source IDs, SHA-256 digests and immutable document versions. The document service uses project/document IDs and checks expectedCurrentVersion inside a SQLite transaction. Manual edits always create an unreviewed version. The export controls download the selected Markdown bytes and a JSON manifest with source contents, digests, links, original artifact identity, review and unresolved findings. An explicit export has its own stored bytes and hash. These download records do not impersonate execution receipts. PDF, TeX, BibTeX, rendered figures and OCR are outside this implementation.
