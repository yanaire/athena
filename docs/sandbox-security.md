# Sandbox security

Offline analysis uses Wasmtime 50.0.3 and WASI Preview 1. In an idle project, use **Settings → Agents & execution → Project execution → Enable offline analysis**. Permission is off by default and scoped to the selected project. For development, `ATHENA_EXECUTION_PROJECTS` can allow specific project IDs and does not accept a wildcard. A saved project setting takes precedence. Athena refuses to enable analysis if the app-owned runtime is unavailable.

| Tool language | Runtime |
|---|---|
| `python` | CPython 3.15.2 WASI; standard-library CSV, JSON, and statistics. No pip, pandas, NumPy, or native extensions. |
| `node` | QuickJS-ng 0.18.0; file I/O through `qjs:std`. No `std.fs`, Node built-ins, npm, DOM, or `fetch`. |

In a QuickJS `.mjs` script, use `import * as std from 'qjs:std'` and read staged text with `std.loadFile('/workspace/input.txt')`. To write a result, open `/outputs/<name>` with `std.open(path, 'w')`, then call `puts(text)` and `close()` on the returned file. Pass only `<name>` in `run_command.outputs`.

The guest can read approved byte snapshots from `/workspace` and write declared filenames under `/outputs`. It inherits no host environment, network capabilities, shell, or credential store. The sandbox caps WebAssembly linear memory at 192 MiB, each output file at 1 MiB and captured output at 16 KiB per stream. A separate native watchdog samples helper memory every 10 ms and terminates it above 768 MiB, including compilation and host calls. On macOS it checks the larger of physical footprint and resident size; on Linux it checks `/proc/self/status` RSS. Failure to read memory accounting also stops execution. The default guest deadline is five seconds plus separate bounded startup.

Published artifacts are checked after successful exit and scratch cleanup. Missing outputs, failed, timed out and cancelled attempts publish no partial artifacts. Each immutable blob is installed from a flushed temporary file. One index rename exposes the entire output batch; caught write or index failures remove the newly installed blobs and preserve the prior namespace. A rollback failure is reported rather than hidden.

The trusted computing base includes the native app and Wasmtime. The helper translates WASM to Pulley bytecode and interprets it. On macOS it runs under Hardened Runtime without permission to generate native executable memory. The native watchdog is sampled enforcement, not an allocation-time OS quota: memory can exceed the threshold between samples, scheduling can delay termination, and Linux RSS excludes swapped pages. It does not limit the Node host or aggregate memory across jobs. Following abrupt host death, a private job scratch directory or unpublished blobs can remain on disk. Index atomicity does not promise filesystem/SQLite atomicity or power-loss durability. Software running under the same macOS account may read or modify workspace files, scratch data, and locally writable runtime components; artifact hashes record the bytes published, not protection from another same-account process. Runtime availability checks verify access, not a fresh integrity check before every execution. Protect the application and workspace from untrusted local software.
