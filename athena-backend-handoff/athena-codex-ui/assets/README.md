# Athena brand assets

The PNG files are reused unchanged from the repository owner’s `yanaire/beta` project, at their request.

- Repository commit: `3aab244b7296035efb8f09a3971fac913fe30efd`
- `athena-icon-128.png`: `src-tauri/icons/128x128.png` (sidebar and About)
- `athena-icon-32.png`: `src-tauri/icons/32x32.png` (browser tab)

Exact Git blob hashes and file sizes are in `provenance.json`. The build embeds the files as PNG data URLs so the standalone app has no external image dependency.
