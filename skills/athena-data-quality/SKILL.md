# 분석 전에 자료의 품질을 확인하라

## 확인 가능한 범위를 정하라

- 현재 호스트의 파일 읽기·집계·변환 도구와 접근 권한을 확인하라.
- 스킬 설명만으로 Python, pandas 또는 정제 도구가 등록되어 있다고 가정하지 마라.
- M2의 read와 고정 calculate_csv는 실제 지원 입력과 통계 범위 안에서만 사용하라.
- 필요한 검사가 지원되지 않으면 수행한 관찰과 미실행 계획을 분리하라.
- 작업과 권한은 Athena TaskManager에 맡기고 별도 스케줄러를 만들지 마라.

## 입력과 관측 단위를 기록하라

- 원본 asset 참조, 버전, 형식, 문자 인코딩과 제공된 스키마를 확인하라.
- 한 행이 사람, 시료, 실험 반복 또는 시계열 샘플 중 무엇인지 적어라.
- 참가자·장치·세션·실험 조건을 연결하는 키와 예상 관계를 확인하라.
- 단위, 샘플링률, 시간대, 측정 범위와 알려진 누락 표기를 수집하라.
- 원본을 보존하고 정제본·제외 목록·변환 이력을 별도로 다루어라.

## 점검 절차를 수행하라

1. 파일을 실제로 읽고 헤더, 구분자, 자료형, 인코딩 및 파싱 경고를 확인하라.
2. 읽기가 잘렸거나 일부 행만 확인했다면 전체 행 수와 품질을 확정하지 마라.
3. 도구로 확인 가능한 전체 행·열 수, 자료형, 결측 수와 중복 키 수를 기록하라.
4. 빈 문자열, 결측 코드, 0, 검출한계 미만 값을 구별하라. 0을 일괄 결측으로 바꾸지 마라.
5. 결측 분포를 조건·참가자·시간별로 검토하라. 자료만 보고 결측 발생 원인을 확정하지 마라.
6. 중복 키가 오류인지 반복 측정인지 확인하라. 같은 값이라는 이유만으로 행을 삭제하지 마라.
7. 날짜 파싱 실패, 시간 역전, 간격 변화, 채널 길이 차이와 시계 동기화 근거를 확인하라.
8. 단위 혼합, 보정 스케일, 범위 이탈과 상수 채널을 구분해 기록하라.
9. 이상치를 후보로 표시하고 원본·장치 기록을 확인하라. 보기 좋은 결과를 위해 자동 제거하지 마라.
10. 파일 결합 시 예상한 일대일·일대다 관계와 결합 전후 행 수를 확인하라.
11. 예측 분석에서는 참가자·세션 중복과 미래 정보 누수를 점검하라. 분할 후 학습 자료에서만 대체·정규화 기준을 추정하라.
12. 삭제·대체·보정 방안을 제시하고, 실제 권한과 도구가 있을 때만 별도 정제본에 적용하라.
13. 변환 후 같은 검사를 반복하고 제거·변경된 행의 수와 이유를 보존하라.

## 다음 형식으로 보고하라

```yaml
status: completed | partial | planned | blocked
source_assets: []             # 실제 원본 참조
coverage: null                # 전체/부분 읽기와 확인된 범위
observation_unit: null
available_evidence: []        # 실제 검사 결과와 도구 근거
quality_findings: []          # 위치, 문제, 영향, 확실성
proposed_transformations: []  # 미실행 변경 및 판단 기준
executed_transformations: []  # 실제 변경만 기록
output_artifacts: []          # 실제 등록된 정제본·제외 목록
proposed_validation: []
unresolved: []                # 미확인 단위, 표본 관계, 미지원 검사
```

## 작은 요청에 적용하라

- 요청 예: “측정 CSV를 평균 내기 전에 결측과 중복을 확인해 줘.”
- 행 수와 독립 참가자 수를 구별하고 반복 측정 키를 먼저 확인하라.
- 일부 행만 읽었다면 관찰한 결측 예와 전체 집계 계획을 분리하라.
- calculate_csv 출력에 없는 중복 수나 누락 원인을 계산된 사실처럼 추가하지 마라.

## 제안 인수 시나리오를 사용하라

- 중복 키, 의도된 반복 측정, 빈 칸, 단위 혼합, 역전된 시각을 넣은 작은 합성 CSV를 제안하라.
- 생성 명세에 기대 건수를 먼저 기록하고 실제 검사 결과와 대조하라.
- 정제 전후 원본 보존과 변경 이력, 미등록 검사 도구의 차단 표시를 확인하라.
