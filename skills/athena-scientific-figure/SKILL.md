# 과학 데이터 그림 작성

보여 주려는 관계를 정하고 원자료에서 그림까지의 변환을 추적하라.
그림 설계, 계산 실행, 파일 생성, 렌더 확인을 각각 구분하라.

## 입력

- 연구 질문, 원자료 위치, 열·변수 의미, 단위, 조건, 표본 구조를 확인하라.
- 기존 요약 통계가 있으면 계산 방법과 표본 수·오차 정의를 확인하라.
- 출력 형식, 크기, 패널 구성, 독자와 캡션 요구를 확인하라.
- 자료가 없으면 필요한 데이터와 그림 설계를 제안하고 가상 데이터는 예시라고 표시하라.

## 기능 확인

- 실제 호스트의 파일 읽기·계산·플로팅·파일 생성·이미지 확인 기능을 점검하라.
- 정해진 CSV 처리 도구가 임의의 코드 실행·플로팅까지 지원한다고 가정하지 마라.
- 도구 이름·라이브러리 설치·버전·내보내기 성공을 추정하지 마라.
- 플로팅 기능이 없으면 축·범례·변환·캡션 설계를 제공하고 `그림 파일 미생성`으로 기록하라.
- 생성 기능은 있어도 이미지 확인 도구가 없으면 시각 검토는 미수행으로 남겨라.

## 절차

1. 비교·분포·시간 변화·관계 중 그림이 답할 질문을 정하라.
2. 원자료의 결측·비수치 값·단위·중복·반복 측정을 확인하고 제외·변환 규칙을 기록하라.
3. 축과 범주를 선택하고 데이터에 맞는 그래프를 정하라. 관측되지 않은 값이나 추세를 채워 넣지 마라.
4. 단위 변환·집계·정규화·보간·모형 적합이 필요하면 실제 계산 경로와 설정을 남겨라.
5. 표본 수와 독립 관측 단위를 구분하라. 반복 측정 점의 수를 독립 표본 수로 표시하지 마라.
6. 오차 막대는 SD·SE·신뢰구간 등 실제 정의를 명시하라. 의미가 불명확하면 임의의 오차 막대를 만들지 마라.
7. 축 이름·단위·범위·눈금·로그 변환을 명시하고, 비교를 오도할 절단이나 서로 다른 패널 척도를 설명하라.
8. 색만으로 구분하지 않도록 선·표식·범례를 함께 사용하라. 데이터와 캡션이 읽히도록 배치하라.
9. 등록된 도구가 지원하면 실제 그림을 생성하고 사용한 자료·스크립트·설정·산출물을 연결하라.
10. 실제 생성 파일의 존재와 형식을 확인하라. 이미지 확인 도구가 있으면 잘림·겹침·단위·범례와 데이터 대응을 검토하라.
11. 캡션에 대상·조건·표본 수·변환·오차 정의·출처를 필요한 만큼 적어라. 통계적 판단은 실제 분석 결과에 근거하라.
12. 생성·검토·내보내기 중 어느 단계까지 수행했는지 보고하라. 계획된 파일명이나 코드만으로 그림 생성 완료를 선언하지 마라.

## 출력 형식

```text
그림 목적 / 데이터 출처:
변수·단위 / 표본 구조:
변환·제외·통계 정의:
그림 설계: 종류 | 축·범위 | 패널 | 범례 | 불확실성 표현
실행 상태: 설계만 / 생성 / 시각 검토 / 일부 실패
캡션:
실제 산출물: 확인한 경로·형식 또는 미생성
재현 정보: 확인한 코드·설정·버전 또는 미확인
남은 확인:
```

원자료의 접근·재사용 조건과 그림에 포함한 외부 이미지의 조건을 따로 기록하라.

## 자체 예시

가상 입력: 시간 `[0, 1, 2]`초, 신호 크기 `[2, 4, 3]`마이크로볼트이며 반복 측정은 없다.

- 시간과 신호 크기의 선·점 그림을 설계하고 두 축에 단위를 표시하라.
- 반복 측정이나 오차 모델이 없으므로 임의의 신뢰구간을 추가하지 마라.
- 캡션에 예시 데이터임을 적고, 플로팅 도구가 없으면 설계만 제공하라.

## 제안 인수 조건

아래 조건은 후속 구현·평가 항목이며 실제 생성·검증 결과가 아니다.

- 원자료와 축 단위, 변환 설정, 캡션의 수치가 연결된다.
- 오차 정의가 없는 입력에서 SD·SE·신뢰구간을 만들어 내지 않는다.
- 파일이 없을 때 생성 완료를, 렌더 확인이 없을 때 시각 검토 완료를 보고하지 않는다.
